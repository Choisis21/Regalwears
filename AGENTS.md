# Regal Wears — Agent Notes

Production-ready fashion e-commerce demo (ladies' wear). Full spec in `Build Prompt.md`.

**Stack:** Next.js 15 (App Router) · TypeScript · Tailwind v4 (CSS `@theme`) · shadcn/ui · Prisma + Supabase Postgres · NextAuth/Auth.js · Stripe + PayPal (test mode) · Cloudinary · Algolia · Resend · Framer Motion · Lucide.

**Build rules (non-negotiable):**
1. Confirm before architectural decisions, new dependencies, deletions, or significant changes.
2. Humanized copy only — warm and conversational, never robotic. No dashes used as commas/sentence separators.
3. Scroll animations on every section/card/image (Framer Motion). Respect `prefers-reduced-motion`.

Build proceeds in phases against the 9 confirmation checkpoints in `Build Prompt.md`.
